## 🌟 Descripción

**CampAventura** es una landing page moderna y profesional diseñada para una empresa de campamentos de verano. Incluye funcionalidades interactivas como mapa del campamento, calculadora de precios, checklist de equipaje, galería con lightbox, y mucho más.

## ✨ Características Principales

### 🎨 Diseño
- ✅ Diseño 100% responsive (mobile-first)
- ✅ Modo oscuro/claro con persistencia
- ✅ Animaciones suaves y parallax
- ✅ Tipografías modernas (Fredoka + Poppins)
- ✅ Paleta de colores aventurera

### 🎯 Funcionalidades Interactivas
- 🗺️ **Mapa interactivo SVG** del campamento
- 💰 **Calculadora de precios** dinámica
- 🎒 **Checklist de equipaje** interactivo
- 📅 **Itinerario diario** animado
- 🖼️ **Galería con lightbox**
- ⏰ **Countdown** al próximo campamento
- 👨‍👩‍👧 **Perfiles de monitores** con hover
- 📝 **Formulario multi-step** de inscripción
- 🔥 **Contador de plazas** con urgencia
- 💬 **Chatbot FAQ** inteligente
- 📰 **Blog/Noticias** integrado
- 🏆 **Sección de certificaciones** y seguridad

### 🛠️ Tecnologías
- HTML5 semántico
- Tailwind CSS (CDN)
- Font Awesome 6.5
- Google Fonts
- JavaScript vanilla (sin dependencias)
